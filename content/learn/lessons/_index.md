# 📚 Lessons

Practical, scenario-based lessons that combine vocabulary, grammar, and culture into a single topic. Each lesson is a complete unit you can study in one sitting.

## What makes these lessons different?

- **Real-world scenarios** — restaurants, travel, weather, daily routines, family
- **Bilingual scaffolding** — Korean summary at the top, English explanation below
- **Cross-references** — wikilinks to atomic concepts (e.g., *food-restaurant-spanish* → *gustar-verb*)
- **Beginner-friendly** — A0–A2 level, no prior knowledge assumed

## Available Lessons

- **Spanish** — colors, family members, food & restaurant, numbers 1–100, telling time, daily routine, travel directions, weather & seasons
- **Korean** — alphabet (Hangul), greetings, basic phrases, particles, pronunciation, family, food, numbers
- **Japanese** — Hiragana basics, Katakana basics, Kanji N5 100, daily routine
- **Russian** — Cyrillic alphabet, pronunciation, greetings, basic phrases, noun cases
- **Chinese** — Pinyin basics, tones, greetings, daily routine

> New lessons are added regularly. Follow the path that matches your target language.
