# 일본어 양사 (助数詞, Counters)

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 양사(助数詞) — 사물의 종류에 따라 다른 단위 사용. 한국어 양사(명사, 개 등)와 비슷.
> - **구조:** 숫자 + 양사 — 예: 一人 (ひとり), 二匹 (にひき), 三本 (さんぼん).
> - **한국어 차이:** 한국어 "사람 한 명" / "고양이 한 마리" / "연필 한 자루" — 구분 명확. 일본어도 비슷.
> - **기본:** 個 (general) + 人 (사람) + 本 (가늘고 긴 것) + 枚 (평평한 것) + 冊 (책) + 匹 (동물) + 回 (횟수) + 時 (시) + 月 (월) + 日 (일)
> - **다음 단계:** 숫자 100+ + 고급 양사

## 양사란?

**양사 (助数詞, josūshi)**는 숫자 뒤에 붙어 사물, 사람, 동물 등을 세는 단어입니다. 사물의 종류에 따라 다른 양사를 사용합니다.

한국어 학습자에게 익숙한 시스템 — 한국어 양사 (명사, 마리, 자루, 권 등)와 유사하지만, 일본어는 더 세분화:

| 한국어 | 일본어 |
|:---|:---|
| 사람 → 명 | 人 |
| 책 → 권 | 冊 |
| 연필/물건 → 자루/개 | 本 (긴 것) / 個 (일반) |
| 동물 → 마리 | 匹 (소형) / 頭 (대형) |
| 번/회 → 번 | 回 |

## 숫자 + 양사 기본 패턴

```
[숫자] + [양사]
```

| 패턴 | 예시 |
|:---|:---|
| 一 + 人 = 一人 (ひとり, 한 사람) | 一人 (hitori) |
| 二 + 本 = 二本 (にほん, 두 병) | 二本 (nihon) |
| 三 + 個 = 三個 (さんこ, 세 개) | 三個 (sanko) |

> **양사에 따라 숫자 발음이 변함** — 예: 一人 = ひとり (NOT いちにん).

## 양사별 숫자 발음 변화

많은 양사가 숫자 발음을 변화시킵니다. 주요 패턴:

| 숫자 | 기본 발음 | 양사와 함께 (변화) |
|:---:|:---|:---|
| 1 | いち (ichi) | ひとり (hitori, with 人) |
| 2 | に (ni) | ふたり (futari, with 人) |
| 4 | し (shi) | よん (yon, with 대부분) / し (with 時/月) |
| 7 | しち (shichi) | なな (nana, with 대부분) |
| 9 | く (ku) | きゅう (kyū, with 대부분) |

> **기억법:** 양사가 h, p, b 로 시작할 때 숫자 끝소리가 변함 (예: 一本 = いっぽん ippon).

## 발음 변화 규칙

| 규칙 | 예시 |
|:---|:---|
| っ before は (h-양사) | 一本 → いっぽん (ipp**onn** = ippon) |
| っ before ぱ (p-양사) | 一枚 → いちまい (변화 없음, mai가 m으로 시작) |
| っ before ば (b-양사) | 一杯 → いっぱい (ippai) |
| び/ぴ/き/ぎ before は/ひ/ふ | 三本 → さんぼん (san**bonn** = sanbon) |

## 한국어 학습자가 자주 하는 실수 5가지

1. **숫자 발음 변화** — 사람 + 1 → 一人 = **ひとり** (NOT いちにん). 양사와 함께일 때 숫자 발음이 변함.
2. **일본어 個 = 한국어 개** — 하지만 個는 일반 (펜, 과일, 공), 匹는 동물, 本은 긴 물건. 한국어는 마리/자루/권/명으로 구분하지만 일본어는 더 세분화.
3. **시 (時) 발음** — 4시 = よじ (NOT しじ), 7시 = しちじ, 9시 = くじ.
4. **월 (月) 발음** — 4월 = しがつ (NOT よがつ), 7월 = しちがつ, 9월 = くがつ.
5. **반대말 혼동** — 一日 = 하루 또는 1일 (날짜). 문맥에 따라 다름.

## 5단계 학습법

### Level 1 — 일반 양사 個
작은 사물을 個로 세는 연습.

### Level 2 — 사람 人
1-10까지 人과 함께 (1, 2 특수 읽기 외우기).

### Level 3 — 긴 물건 本
병, 펜 등을 本으로 세는 연습.

### Level 4 — 평평한 물건 枚
종이, 사진 등을 枚로 세는 연습.

### Level 5 — 시간 + 날짜
時, 月, 日 함께 연습.
