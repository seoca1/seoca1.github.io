# About

This site is a continuously evolving collection of language learning resources for English speakers. It currently covers **Spanish, Japanese, Chinese, Russian, and Korean**.

## How it's built

- **Hugo** static site generator with the Ananke theme
- **Multilingual** via Hugo's i18n (`en` default + `ko` mirror)
- **Content** — atomic concept notes + scenario-based lessons + cultural posts
- **Auto-deployed** — content is committed to GitHub and deployed via GitHub Actions

## What you'll find

- **Concepts** — atomic grammar notes (tense, verb pattern, pronoun rule)
- **Lessons** — practical scenario-based units (restaurant, travel, daily routine)
- **Culture** — context that makes vocabulary stick
- **Languages** — per-language landing pages (Russian, Japanese, Chinese, Korean)
