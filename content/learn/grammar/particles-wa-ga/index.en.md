# 일본어 조사: は・が・を (Particles は・が・을)

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 조사 (助詞) 3개. **문장 구조의 핵심** — 한국어 조사와 비슷하지만 차이 있음.
> - **は (ha/wa):** 화제/주제 표시. 발음은 "ha"지만 조사일 땐 "**wa**". 日本語 では (nihongo de wa).
> - **が (ga):** 주어/목적어 강조. 私が行きます (watashi ga ikimasu).
> - **을 (wo):** 직접 목적어. 발음 "wo"지만 한자 없을 땐 "o"로 표기. 本を読みます.
> - **한국어 차이:** 은/는 (보조사) ↔ が (주어 강조), 와/과 (접속 조사) ≠ 을 (목적어).
> - **다음 단계:** [[Verb_Groups]] (동사 3그룹) + [[Daily_Routine_Japanese]]

## 조사란?

**조사 (助詞, joshi)**는 명사, 동사 등 단어 뒤에 붙어 **문법적 역할**을 표시하는 작은 히라가나 단어입니다. 영어의 전치사(preposition)와 비슷하지만 **단어 뒤에** 붙는다는 점이 다릅니다. 한국어 조사와 유사.

조사는 **필수** — 명사/동사를 다 알아도 조사가 틀리면 문장이 어색하거나 의미가 달라집니다.

## N5 핵심 조사 3개

### は (wa) — 화제/주제

> **기능:** 문장의 **화제(topic)** 표시 (무엇에 대해 말하는가) 또는 대조.
> **발음:** 알파벳으로는 "ha"이지만, 조사로 쓰일 때는 **"wa"** 로 발음.

| 용법 | 예시 | 읽기 | 의미 |
|:---|:---|:---|:---|
| 화제 표시 | 日本は美しいです | Nihon wa utsukushii desu | (말하자면) 일본은 아름답습니다 |
| 대조 | 私は学生です、あなたは先生です | Watashi wa gakusei desu, anata wa sensei desu | 저는 학생이고, 당신은 선생님입니다 |
| 의문사 + 화제 | どこが好きですか | Doko ga suki desu ka | 어디가 좋으세요? (NOT どこは) |

> **핵심 통찰:** は는 **문법적 주어**가 아니라 **화제**를 표시. 한국어 은/는과 비슷한 역할.

### が (ga) — 주어/강조

> **기능:** 행위의 **주체(subject)** 표시. 특히 주어가 **새 정보**이거나 **강조**될 때 사용.

| 용법 | 예시 | 읽기 | 의미 |
|:---|:---|:---|:---|
| 행위의 주체 | 犬が走っています | Inu ga hashitte imasu | 개가 달리고 있습니다 |
| 새 정보 | あ、雨が降っています | A, ame ga futte imasu | 아, 비가 오고 있네요 |
| 식별 | 誰が来ましたか | Dare ga kimashita ka | 누가 왔나요? (식별) |
| 소유 (aru 패턴) | お金があります | Okane ga arimasu | 돈이 있습니다 |
| 형용사 주어 | 水が冷たいです | Mizu ga tsumetai desu | 물이 차갑습니다 |

> **핵심 통찰:** が는 **행위의 주체** — 한국어 이/가와 비슷.

### を (wo/o) — 직접 목적어

> **기능:** **직접 목적어** 표시 — 타동사가 영향을 주는 대상.
> **발음:** "o" (현대), "wo" (전통/공식).

| 용법 | 예시 | 읽기 | 의미 |
|:---|:---|:---|:---|
| 직접 목적어 | 本を読みます | Hon wo yomimasu | 책을 읽습니다 |
| 이동 경로 | 公園を歩きます | Kōen wo arukimasu | 공원을 걸습니다 (가로질러) |
| 떠나기 | 大学を卒業します | Daigaku wo sotsugyō shimasu | 대학을 졸업합니다 |

> **핵심 통찰:** 을는 **동사의 대상**. 한국어 을/를과 비슷.

## 비교표

| 조사 | 한국어 대응 | 기능 | 표시 |
|:---:|:---|:---|:---|
| は | 은/는 (화제) | 화제/주제 | 무엇에 대해 말하는가 |
| が | 이/가 (주어) | 주어/강조 | 누가/무엇이 행동을 하는가 |
| 을 | 을/를 (목적어) | 직접 목적어 | 무엇이 행동을 받는가 |

## 한국어/일본어 대조 예시

| 일본어 | 한국어 | 번역 |
|:---|:---|:---|
| 私は学生です | 저는 학생입니다 | 저는 학생입니다 |
| 先生が本を持っています | 선생님이 책을 가지고 있습니다 | 선생님이 책을 가지고 있습니다 |
| 私は先生の本を読みます | 저는 선생님의 책을 읽습니다 | 저는 선생님의 책을 읽습니다 |
| どこが好きですか | 어디가 좋습니까 | 어디가 좋으세요? |

## 문장 내 조사 위치

**한국어:** 주어 + 목적어 + 동사 (SOV)  
**일본어:** 화제/주어 + 목적어 + 서술어 (SOV)

| 위치 | 한국어 | 일본어 | 조사 |
|:---:|:---|:---|:---|
| 1 | 나 (I) | 私 (watashi) | は (화제) |
| 2 | 공부를 (study) | 勉強を (benkyō wo) | 을 (목적어) |
| 3 | 한다 | します | (동사) |

따라서: **私は勉強をします** = 나는 공부를 합니다

## 조사 + 동사 패턴

### 을를 취하는 타동사

| 동사 | 예시 | 의미 |
|:---|:---|:---|
| 食べ**ます** (tabemasu) | りんごを食べます | 사과를 먹습니다 |
| 飲み**ます** (nomimasu) | 水を飲みます | 물을 마십니다 |
| 読み**ます** (yomimasu) | 本を読みます | 책을 읽습니다 |
| 聞き**ます** (kikimasu) | 音楽を聞きます | 음악을 듣습니다 |
| 見**ます** (mimasu) | 映画を見ます | 영화를 봅니다 |
| 買います (kaimasu) | 靴を買います | 신발을 삽니다 |

### 가를 취하는 자동사 (주어)

| 동사 | 예시 | 의미 |
|:---|:---|:---|
| 行き**ます** (ikimasu) | 私が行きます | 제가 갑니다 |
| 来**ます** (kimasu) | 母が来ます | 어머니가 옵니다 |
| 降り**ます** (furimasu) | 雨が降ります | 비가 내립니다 |
| 鳴**ります** (narimasu) | 犬が鳴ります | 개가 짖습니다 |

## は vs 가 결정 트리

> **질문:** 주어가 청자에게 **이미 알려진** 정보인가, **새로운 정보**인가?

```
1. 주어가 이미 알려진/확정된 정보인가?
   → 예: は (화제)
   → 아니오: 계속

2. 행동의 주체 또는 새 정보인가?
   → 예: が (주어)
```

| 상황 | 조사 | 예시 |
|:---|:---|:---|
| 자기소개 | は | 私は田中です (저는 다나카입니다) |
| 새 사람이 나타남 | が | あ、田中さんが来ました (아, 다나카 씨가 왔네요) |
| 일상 루틴 설명 | は | 私は毎朝コーヒーを飲みます (저는 매일 아침 커피를 마십니다) |
| 사건 보고 | が | 今日、地震がありました (오늘 지진이 있었습니다) |
| 식별 (어느 것?) | が | どの車ですか (어떤 차인가요?) → 赤い車が好きです (빨간 차가 좋습니다) |

## 한국어 학습자가 자주 하는 실수 5가지

1. **는 → は (X)** — 한국어 은/는 → 일본어 は (화제). NOT が. 초보자가 は 자리에 を 넣는 경우 많음.
2. **이/가와 를은 다름** — 한국어 이/가 (주어) ↔ 일본 が, 한국 을/를 (목적어) ↔ 일본 을. 혼동 금지.
3. **は + 가 동시 사용 금지** — 한 명사구에 は와 가를 동시에 쓰지 마세요. 私**は**学生です (저는 학생입니다), NOT 私**は**学生**が**です.
4. **의문사는 が** — 의문사 + は (X), 의문사 + が (O). どこ**が**好き? (어디가 좋아요?), NOT どこ**は**好き?
5. **自動사에 을 사용 금지** — 行く (가다) 는 자동사. 学校に**行きます** (학교**에** 갑니다), NOT 学校**を**行きます.

## 조사 결합

한 단어에 여러 조사가 겹칠 수 있습니다:

| 패턴 | 예시 | 의미 |
|:---|:---|:---|
| には (화제 + 방향) | 学校には行きます | 학교에는 (말하자면) 갑니다 |
| では (수단) | 日本語では | 일본어에서는 |
| とは (화제 + 인용) | 「ありがとう」とは | "ありがとう"라는 말의 뜻 |
| への (방향 + 소유격) | 東京への道 | 도쿄로 가는 길 |

## 자가 점검 (한국어로 번역하세요)

1. 저는 학생입니다. (は 사용)
2. 다나카는 물을 마십니다. (が・을 사용)
3. 책은 어디입니까? (의문사 + 조사)
4. 저는 초밥을 좋아합니다. (가 사용)
5. 저는 돈이 없습니다. (부정 + 소유 패턴)

> **정답:** 1. 私は学生です  2. 田中さんが水を飲みます  3. 本はどこですか  4. 私は寿司が好きです  5. お金がありません
