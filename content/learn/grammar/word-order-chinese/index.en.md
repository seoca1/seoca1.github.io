# 중국어 어순 (Word Order, 语序)

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 중국어 어순은 **SVO** (주어 + 동사 + 목적어) — 한국어 SOV와 다름.
> - **한국어 vs 중국어:** 한국어 "나는 밥을 먹는다" (SOV) → 중국어 "我吃饭" (SVO). **목적어 + 동사 순서 반대**.
> - **시간 표현:** 시간 + 동사 (한국어 "7시에 일어난다" → 중국어 "7点起床").
> - **부정:** 不/没 + 동사 (예: 我不吃, 我没吃).
> - **한국어 학습자 주의:** 한국어 어순대로 번역하면 안 됨. 처음부터 중국어 어순으로 사고.
> - **다음 단계:** [[Basic_Particles_Chinese]] 심화 + 심화 어순

---

## 중국어 어순이란?

중국어는 **SVO (Subject + Verb + Object)** 구조 — 영어와 비슷하지만 한국어와 다름.

| 언어 | 어순 | 예시 |
|:---|:---|:---|
| 한국어 | **SOV** | 나는 밥을 먹는다 |
| 중국어 | **SVO** | 我吃饭 (wǒ chī fàn) |
| 영어 | SVO | I eat rice |

**한국어 학습자 최대 함정:** 한국어 어순 (목적어 + 동사) 그대로 번역. 처음부터 **중국어 어순 (동사 + 목적어)** 으로 사고해야 함.

## 5대 기본 어순

### 1. 주어 + 동사 + 목적어 (SVO)

> **가장 흔한 패턴.**

| 한국어 | 중국어 | 병음 |
|:---|:---|:---|
| 나는 밥을 먹는다 | 我吃饭 | wǒ chī fàn |
| 나는 책을 읽는다 | 我看书 | wǒ kàn shū |
| 너는 영화를 본다 | 你看电影 | nǐ kàn diàn yǐng |
| 그는 커피를 마신다 | 他喝咖啡 | tā hē kā fēi |

> **규칙:** 동사 + 직접 목적어. 조사 없음.

### 2. 주어 + 동사 + 보어 (SVC)

> **상태 묘사 (形容詞, 형용사).**

| 한국어 | 중국어 | 병음 |
|:---|:---|:---|
| 나는 행복하다 | 我幸福 | wǒ xìng fú |
| 그녀는 예쁘다 | 她漂亮 | tā piào liang |
| 그것은 좋다 | 那个好 | nà ge hǎo |

> **주의:** 한국어 "~이다" 동사처럼 是不 없이 형용사만 사용.

### 3. 시간 + 동사 + 목적어

> **시간 표현이 동사 앞에 옴.**

| 한국어 | 중국어 | 병음 |
|:---|:---|:---|
| 나는 매일 운동한다 | 我每天运动 | wǒ měi tiān yùn dòng |
| 그는 어제 학교에 갔다 | 他昨天去学校 | tā zuó tiān qù xué xiào |
| 나는 7시에 일어난다 | 我七点起床 | wǒ qī diǎn qǐ chuáng |

### 4. 장소 + 동사 + 목적어

> **장소 표현이 동사 앞에 옴.**

| 한국어 | 중국어 | 병음 |
|:---|:---|:---|
| 나는 한국에서 살다 | 我在韩国住 | wǒ zài Hán guó zhù |
| 그는 집에서 일한다 | 他在家工作 | tā zài jiā gōng zuò |
| 나는 도서관에서 공부한다 | 我在图书馆学习 | wǒ zài tú shū guǎn xué xí |

### 5. 부사 + 동사

> **부사 (빈도/정도) + 동사.**

| 한국어 | 중국어 | 병음 |
|:---|:---|:---|
| 나는 자주 운동한다 | 我经常运动 | wǒ jīng cháng yùn dòng |
| 너는 항상 늦는다 | 你总是迟到 | nǐ zǒng shì chí dào |
| 그는 매우 빨리 달린다 | 他跑得非常快 | tā pǎo de fēi cháng kuài |

## 한국어 vs 중국어 어순 비교

### 기본 문장

| 한국어 (SOV) | 중국어 (SVO) | 차이점 |
|:---|:---|:---|
| 나는 밥을 먹는다 | 我吃饭 | 한국어: 동사 끝 / 중국어: 동사 중간 |
| 너는 영화를 본다 | 你看电影 | 동일 |
| 그는 집에 간다 | 他回家 | 동일 |

### 시간 표현

| 한국어 | 중국어 | 차이점 |
|:---|:---|:---|
| 나는 매일 운동한다 | 我每天运动 | 한국어: 시간 + 주어 / 중국어: 주어 + 시간 |
| 그는 어제 갔다 | 他昨天去了 | 동일 |
| 나는 7시에 일어난다 | 我七点起床 | 동일 |

### 장소 표현

| 한국어 | 중국어 | 차이점 |
|:---|:---|:---|
| 나는 학교에서 공부한다 | 我在学校学习 | 한국어: 에서 / 중국어: 在 + 장소 |
| 그는 집에서 일한다 | 他在家工作 | 동일 |

### 부사

| 한국어 | 중국어 | 차이점 |
|:---|:---|:---|
| 나는 자주 운동한다 | 我经常运动 | 한국어: 부사 + 동사 / 중국어: 부사 + 동사 |
| 너는 매우 빨리 달린다 | 你跑得非常快 | 한국어: 매우 + 빨리 / 중국어: 매우 (부사) → 동사 + 得 (구조보어) + 매우 + 빠르다 |

## 의문문 어순

### 일반 의문문 (陈述句 + 吗)

| 어순 | 패턴 |
|:---|:---|
| 평서문 | 我是韩国人 (나는 한국인이다) |
| 의문문 | 你是韩国人吗? (너는 한국인이니?) |

> **구조:** 평서문 끝에 吗 (ma) 붙임. 어순 변화 없음.

### 의문사 의문문

| 의문사 | 의미 | 예시 |
|:---|:---|:---|
| 谁 (shéi) | 누가 | 谁是你朋友? (누가 너의 친구니?) |
| 什么 (shén me) | 무엇 | 你吃什么? (너 무엇 먹니?) |
| 哪里 (nǎ lǐ) | 어디 | 你住哪里? (너 어디 사니?) |
| 几 (jǐ) | 몇 (10 이하) | 你有几个朋友? (너 친구 몇 명이니?) |
| 多少 (duō shao) | 얼마나 (11 이상/돈) | 多少钱? (얼마니?) |
| 什么时候 | 언제 | 你什么时候来? (너 언제 오니?) |
| 为什么 | 왜 | 你为什么学习中文? (너 왜 중국어 공부하니?) |
| 怎么 | 어떻게 | 你怎么去? (너 어떻게 가니?) |

> **구조:** 의문사 + 평서문 + ? . 어순 변화 없음.

## 부정 어순

### 不 (bù) — 일반 부정 (현재/미래)

```
[주어] + 不 + [동사] + [목적어]
```

| 긍정 | 부정 | 의미 |
|:---|:---|:---|
| 我吃 | 我不吃 | 나는 먹는다 / 먹지 않는다 |
| 我是 | 我不是 | 나는 ~이다 / 아니다 |
| 我去 | 我不去 | 나는 간다 / 가지 않는다 |

### 没 (méi) — 과거 부정

```
[주어] + 没 + [동사] + [목적어]
```

| 긍정 | 부정 | 의미 |
|:---|:---|:---|
| 我吃了 | 我没吃 | 나는 먹었다 / 안 먹었다 |
| 我去了 | 我没去 | 나는 갔다 / 안 갔다 |
| 我看了 | 我没看 | 나는 봤다 / 안 봤다 |

> **한국어 학습자 팁:** 不 = 현재 부정, 没 = 과거 부정. 한국어 "안 ~했어" = 没 (méi).

## 회화 패턴

### 어순 강조 연습

> **A:** 你什么时候去中国?
> (Nǐ shén me shí hou qù Zhōng guó?)
> (너 언제 중국에 가니?)
>
> **B:** 我明年去中国。
> (Wǒ míng nián qù Zhōng guó.)
> (내년에 중국에 가요.)
>
> **A:** 你跟谁一起去?
> (Nǐ gēn shéi yī qǐ qù?)
> (누구랑 같이 가니?)
>
> **B:** 我跟我的朋友一起去。
> (Wǒ gēn wǒ de péng yǒu yī qǐ qù.)
> (내 친구랑 같이 가요.)

### SVO 강조

> **A:** 你吃什么?
> (Nǐ chī shén me?)
> (너 뭐 먹니?)
>
> **B:** 我吃中国菜。
> (Wǒ chī Zhōng guó cài.)
> (나는 중국 음식 먹어요.)

## 한국어 학습자가 자주 하는 실수 5가지

1. **SOV 그대로 번역** — "나는 밥을 먹는다" → 我饭吃 (X) / 我吃饭 (O). 동사 + 목적어 순서 필수.
2. **한국어 조사 사용** — "나는 (은)" = 我 (조사 없음). "을/를" 사용 안 함.
3. **형용사 + 이다 혼동** — 한국어 "예쁘다" = 漂亮 (piào liang). 是不 없이.
4. **시간 + 동사 순서** — "7시에 일어난다" → 7点起床 (시간 + 동사). 한국어 "동사 + 시간" 과 다름.
5. **부정 위치** — 不/没는 동사 앞에. "나는 안 먹어" → 我不吃. 한국어 "동사 + 안" 과 다름.

## 4단계 학습법

### Level 1 — SVO 기본
주어 + 동사 + 목적어 패턴.

### Level 2 — 시간 표현
시간 + 동사 + 목적어.

### Level 3 — 장소 + 부사
在 + 장소 / 부사 + 동사.

### Level 4 — 의문문 + 부정
의문사 의문문 / 不/没 부정.
