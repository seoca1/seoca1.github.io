# 중국어 기본 조사 (的/了/在/有)

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 중국어 가장 흔한 조사/구조 4종: 的 (소유격 "~의"), 了 (완료 "~했음"), 在 (존재/위치 "~에 있다"), 有 (소유 "있다").
> - **한국어 차이:** 한국어 조사와 비슷하지만 더 단순. (1) 의 = ~의, (2) 료 = 과거/완료, (3) 재 = 위치, (4) 유 = 소유.
> - **구조:** 명사 + 의 + 명사 (예: 我的书 = 나의 책), 동사 + 료 (예: 吃了 = 먹었다).
> - **한국어 학습자 팁:** "의/료/재"는 한국 한자음과 비슷. 但 중국 발음 = de/le/zài, **한국 한자음과 다름**.
> - **다음 단계:** [[Word_Order_Chinese]] + 심화 조사 (吗/呢/吧)

---

## 조사란?

중국어는 한국어와 달리 **조사 시스템이 매우 단순**합니다. 핵심 조사 4종만 마스터하면 HSK 1-3 수준의 문장 대부분 구성 가능.

| 조사 | 병음 | 의미 | 한국어 비교 |
|:---:|:---:|:---|:---|
| **的** | de | 소유격 "~의" | 의 |
| **了** | le | 완료 "~했음" | ~었/았음 |
| **在** | zài | 존재/위치 "~에 있다" | 에/에서 |
| **有** | yǒu | 소유 "있다" | 있다 |

## 1. 의 (的, de) — 소유격

> **기능:** "~의" — 명사 사이의 소유/수식 관계.

### 기본 구조

```
[소유자] + 的 + [소유물]
```

| 패턴 | 예시 | 한국어 |
|:---|:---|:---|
| 我的书 | wǒ de shū | 나의 책 |
| 他的车 | tā de chē | 그의 차 |
| 老师的桌子 | lǎo shī de zhuō zi | 선생님의 책상 |

### 회화

> **A:** 这是谁的书?
> (Zhè shì shéi de shū?)
> (이건 누구 책이에요?)
>
> **B:** 这是我的书。
> (Zhè shì wǒ de shū.)
> (이건 제 책이에요.)

### 的 사용 규칙

| 상황 | 의 사용 | 예시 |
|:---|:---:|:---|
| 소유/소속 | O | 我的朋友 (나의 친구) |
| 형용사 + 명사 | O | 漂亮的女孩 (예쁜女孩) |
| 사람 + 명사 | O | 中国朋友 (중국 친구) |
| 사물 + 사물 | X | 红色的车 (빨간 차), 红色는 형용사이므로 의 OK |

> **예외:** 한국어 "의"와 달리, **소유자가 명시적이거나 형용사 수식일 때도 사용.**

## 2. 료 (了, le) — 완료

> **기능:** "~했음" — 행동의 완료 또는 상태 변화.

### 위치 1: 동사 뒤 (동작 완료)

```
[주어] + [동사] + 了 + [목적어]
```

| 패턴 | 예시 | 한국어 |
|:---|:---|:---|
| 吃了 | chī le | 먹었다 |
| 看了 | kàn le | 봤다 |
| 买了 | mǎi le | 샀다 |
| 看了电影 | kàn le diàn yǐng | 영화를 봤다 |

### 위치 2: 문장 끝 (상태 변화)

```
[주어] + [형용사/동사] + 了
```

| 패턴 | 예시 | 한국어 |
|:---|:---|:---|
| 我累了 | wǒ lèi le | 나는 피곤해졌다 |
| 他走了 | tā zǒu le | 그는 갔다 |
| 下雨了 | xià yǔ le | 비가 왔다 |

### 了 사용 규칙

| 상황 | 의미 | 예시 |
|:---|:---|:---|
| 과거 사실/완료 | 동작이 끝남 | 我吃了饭 (나는 밥을 먹었다) |
| 상태 변화 | 새로운 상태 | 我懂了 (나는 이해했다) |
| 미래 강조 | 곧 ~할 것 | 走了! (가자!) |

> **한국어 학습자 주의:** "了"는 한국어 "았/었/했" 보다 넓은 의미. **과거 + 완료 + 변화** 모두 표현.

## 3. 재 (在, zài) — 위치/진행

> **기능:** 위치 ("~에 있다") 또는 진행 ("~하고 있다").

### 용법 1: 위치 (存在)

```
[사물] + 在 + [장소]
```

| 패턴 | 예시 | 한국어 |
|:---|:---|:---|
| 猫在床上 | māo zài chuáng shang | 고양이가 침대 위에 있다 |
| 老师在教室 | lǎo shī zài jiào shì | 선생님이 교실에 있다 |

> **한국어 학습자 팁:** 한국어 "~에 있다" 와 직접 매핑.

### 용법 2: 진행

```
[주어] + 在 + [동사] + [목적어]
```

| 패턴 | 예시 | 한국어 |
|:---|:---|:---|
| 在吃饭 | zài chī fàn | 밥 먹고 있다 |
| 在学习 | zài xué xí | 공부하고 있다 |
| 我在看书 | wǒ zài kàn shū | 나는 책 읽고 있다 |

### 在 vs 了 비교

| 상황 | 조사 | 예시 |
|:---|:---|:---|
| 진행 중 | 在 | 我在吃饭 (나는 밥 먹고 있다) |
| 이미 완료 | 了 | 我吃了饭 (나는 밥 먹었다) |

## 4. 유 (有, yǒu) — 소유/존재

> **기능:** "~가 있다" — 소유 또는 존재 표현.

### 용법 1: 소유

```
[주어] + 有 + [목적어]
```

| 패턴 | 예시 | 한국어 |
|:---|:---|:---|
| 我有车 | wǒ yǒu chē | 나는 차가 있다 |
| 他有两个哥哥 | tā yǒu liǎng gè gē ge | 그는 오빠 두 명이 있다 |

### 용법 2: 존재 (장소 + 사물)

```
[장소] + 有 + [사물]
```

| 패턴 | 예시 | 한국어 |
|:---|:---|:---|
| 桌上有书 | zhuō shang yǒu shū | 책상 위에 책이 있다 |
| 教室里有学生 | jiào shì li yǒu xué shēng | 교실에 학생이 있다 |

### 有 부정: 没有 (méi yǒu)

| 긍정 | 부정 | 의미 |
|:---|:---|:---|
| 有 | 没有 | 있다 / 없다 |
| 我有 | 我没有 | 나는 있다 / 없다 |
| 教室里有 | 教室里没有 | 교실에 있다 / 없다 |

> **한국어 학습자 팁:** 한국어 "있다/없다" 와 직접 매핑. 没有 (méi yǒu) 가 부정이지만 **不有** (bù yǒu) 는 사용 안 함.

## 조사 결합 패턴

### 的 + 다른 조사

| 패턴 | 예시 | 의미 |
|:---|:---|:---|
| 我在中国 | wǒ zài Zhōng guó | 나는 중국에 있다 |
| 中国的朋友 | Zhōng guó de péng yǒu | 중국의 친구 |
| 我的中国朋友 | wǒ de Zhōng guó péng yǒu | 나의 중국 친구 |

### 了 + 其他 위치

| 패턴 | 예시 | 의미 |
|:---|:---|:---|
| 吃了 | chī le | 먹었다 |
| 不吃了 | bù chī le | 더 안 먹겠다 |
| 还没吃 | hái méi chī | 아직 안 먹었다 |

## 실전 회화

### 자기소개 + 소유

> **A:** 你叫什么名字?
> (Nǐ jiào shén me míng zì?)
>
> **B:** 我叫王明。我是韩国人。
> (Wǒ jiào Wáng Míng. Wǒ shì Hán guó rén.)
>
> **A:** 你有中国朋友吗?
> (Nǐ yǒu Zhōng guó péng yǒu ma?)
> (중국 친구가 있어요?)
>
> **B:** 有。我有三个中国朋友。
> (Yǒu. Wǒ yǒu sān gè Zhōng guó péng yǒu.)
> (있어요. 중국 친구가 3명 있어요.)

### 현재 위치

> **A:** 你妈妈在哪里?
> (Nǐ mā ma zài nǎ lǐ?)
> (엄마가 어디 계세요?)
>
> **B:** 我妈妈在家。她在做饭。
> (Wǒ mā ma zài jiā. Tā zài zuò fàn.)
> (엄마는 집에 계세요. 요리하고 있어요.)

### 과거 사건

> **A:** 你昨天吃什么了?
> (Nǐ zuó tiān chī shén me le?)
> (어제 뭐 먹었어요?)
>
> **B:** 我吃了中国菜。很好吃!
> (Wǒ chī le Zhōng guó cài. Hěn hǎo chī!)
> (중국 음식 먹었어요. 맛있었어요!)

## 비교표

| 한국어 | 중국어 | 조사 |
|:---|:---|:---|
| 나의 책 | 我的书 | 的 |
| 너의 친구 | 你的朋友 | 的 |
| 먹었다 | 吃了 | 了 |
| 갔다 | 走了 | 了 |
| 집에 있다 | 在家 | 在 |
| 한국에 있다 | 在韩国 | 在 |
| 공부하고 있다 | 在学习 | 在 |
| 차가 있다 | 有车 | 有 |
| 친구가 없다 | 没有朋友 | 没有 |
| 5명 있다 | 有五个 | 有 |

## 한국어 학습자가 자주 하는 실수 5가지

1. **한국 한자음 의존** — 의 (한국) ≠ de (중국). 발음 다름.
2. **了 생략** — 중국어는 과거/완료 표현에 了 필수. 한국어 과거형처럼 "먹었다" = 吃了.
3. **没有 ≠ 不有** — 부정은 没有 (méi yǒu). 不有 (bù yǒu) 사용 안 함.
4. **在 위치 vs 진행 혼동** — 문맥으로 구분. "他在家" (그는 집에 있다) vs "他在看书" (그는 책 읽고 있다).
5. **的 과용** — 사물 + 사물 수식에도 的 사용 가능. 红色的车 (빨간 차), 大的房子 (큰 집).

## 5단계 학습법

### Level 1 — 的 (소유격)
명사 + 的 + 명사 패턴.

### Level 2 — 了 (완료)
동사 + 了 패턴.

### Level 3 — 在 (위치/진행)
在 + 장소 / 在 + 동사.

### Level 4 — 有 (소유)
有 + 명사 / 没有 (부정).

### Level 5 — 조사 결합
的 + 了 + 在 + 有 한 문장 내 활용.

## 역할극: 일상 대화 (10분)

### 시나리오 A — 친구 방문

> **A:** 你好! 这是你的书吗?
> (Nǐ hǎo! Zhè shì nǐ de shū ma?)
> (안녕! 이거 너의 책이야?)
>
> **B:** 是的。谢谢!
> (Shì de. Xiè xie!)
> (응. 고마워!)
>
> **A:** 不客气。你吃午饭了吗?
> (Bù kè qi. Nǐ chī wǔ fàn le ma?)
> (천만에. 점심 먹었어?)
>
> **B:** 还没吃。我饿了。我们一起去吃饭吧?
> (Hái méi chī. Wǒ è le. Wǒ men yī qǐ qù chī fàn ba?)
> (아직 안 먹었어. 배고파. 같이 밥 먹으러 가자!)

### 핵심 표현

| 중국어 | 병음 | 의미 |
|:---|:---|:---|
| 你的... | nǐ de... | 너의... |
| 我吃了 | wǒ chī le | 나는 먹었다 |
| 我在... | wǒ zài... | 나는 ~에 있다/~하고 있다 |
| 我有... | wǒ yǒu... | 나는 ~가 있다 |
| 我没有... | wǒ méi yǒu... | 나는 ~가 없다 |

## 자가 점검 (중국어로 번역)

1. 이건 나의 책이다.
2. 나는 밥을 먹었다.
3. 나는 지금 공부하고 있다.
4. 나는 차가 있다.
5. 나는 시간이 없다.

> **정답:** 1. 这是我的书。 2. 我吃了饭。 3. 我在学习。 4. 我有车。 5. 我没有时间。
