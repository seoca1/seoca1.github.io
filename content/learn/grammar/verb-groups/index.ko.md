# 일본어 동사 3그룹 (動詞のグループ)

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 동사는 3그룹: グループ1 (五段동사, 어간 끝 자음), グループ2 (一段동사, 어간 끝 -i/-e), グループ3 (불규칙 동사 する/来る).
> - **한국어와 차이:** 한국어는 동사 어미만 바뀌면 끝. 일본어는 동사 **어간(stem)** 을 먼저 찾고 그룹별로 어미 다름.
> - **그룹1 (五段):** 어간 마지막 글자가 자음으로 끝남, 5단 변화 (う→く→ぐ→す→つ→ぬ→ぶ→む→る). 예: 飲む → 飲みます/飲んだ/飲んで.
> - **그룹2 (一段):** 어간이 -i(い) 또는 -e(え)로 끝남. 예: 食べる → 食べます/食べた/食べて.
> - **그룹3 (불규칙):** する/来る만. 예: 勉強する → 勉強します/勉強した.
> - **한국어 학습자 주의:** '~다/어요/습니다' 단순 어미 변화와 다름. 어간 + 변화형 이해 필수.

---

## 일본어 동사 그룹이란?

일본어 동사 (動詞, dōshi)는 활용 방식에 따라 **3그룹**으로 분류됩니다. 한국어는 동사 어미만 바뀌면 되지만, 일본어는 동사 **어간의 마지막 음절**에 따라 활용 패턴이 완전히 달라집니다.

**한국어 학습자에게 가장 어려운 점:** 한국어에 없는 **그룹 2 (-e/-i 어간)** 분류. 한국어 "먹다/자다"는 모두 ~다/어요/습니다로 통일되지만, 일본어는 食べる/寝る가 다른 그룹.

## 그룹 분류

| 그룹 | 명칭 | 어간 끝 | 일반 패턴 | 예시 |
|:---:|:---|:---|:---|:---|
| **1** | 五段 (godan) | 자음 | 5행 모음 변화 | 飲む, 話す, 行く, 読む |
| **2** | 一段 (ichidan) | -i / -e | -i + -masu / -e + 기타 | 食べる, 見る, 起きる |
| **3** | 不規則 (fukisokuki) | 불규칙 | 2개 동사만 | する, 来る |

## 그룹 1: 五段동사 (godan)

어간이 **자음**으로 끝나는 동사. 활용 시 어간 모음이 5개 모음(a, i, u, e, o)을 순환합니다.

### 활용 패턴

| 형식 | 패턴 | 예시 (飲む nomu) |
|:---|:---|:---|
| 사전형 | -u | 飲む (마시다) |
| ます (정중 현재) | -i + ます | 飲みます |
| ません (정중 부정) | -i + ません | 飲みません |
| ました (정중 과거) | -i + ました | 飲みました |
| ませんでした (정중 과거 부정) | -i + ませんでした | 飲みませんでした |
| て형 | 다양 | 飲んで |
| た (평어 과거) | 다양 | 飲んだ |
| 조건형 (-eba) | -e + ば | 飲めば |
| 의지형 (-ou) | -o + う | 飲もう |
| 가능형 (-eru) | -e + る | 飲める |
| 수동형 (-areru) | -a + れる | 飲まれる |
| 사역형 (-aseru) | -a + せる | 飲ませる |

### 그룹 1의 9가지 하위 분류

그룹 1 동사는 마지막 자음에 따라 9가지로 나뉩니다:

| 하위 분류 | 사전형 | ます형 | 예시 동사 |
|:---|:---|:---|:---|
| **う** | -u | -i + ます | 言う (말하다) → 言います |
| **く** | -ku | -i + ます | 書く (쓰다) → 書きます |
| **ぐ** | -gu | -i + ます | 泳ぐ (수영하다) → 泳ぎます |
| **す** | -su | -i + ます | 話す (말하다) → 話します |
| **つ** | -tsu | -i + ます | 待つ (기다리다) → 待ちます |
| **ぬ** | -nu | -i + ます | 死ぬ (죽다) → 死にます |
| **ぶ** | -bu | -i + ます | 遊ぶ (놀다) → 遊びます |
| **む** | -mu | -i + ます | 読む (읽다) → 読みます |
| **る** | -ru | -i + ます | 作る (만들다) → 作ります |

> **주의:** 일부 그룹 1 동사가 **-ru** 로 끝남 (예: 走る, 作る). 그룹 2 와 혼동 주의!

## 그룹 2: 一段동사 (ichidan)

어간이 **-i**(드물게 -e)로 끝나는 동사. 활용이 더 쉬움 — 마지막 -i/-e를 떼고 어미 붙임.

### 활용 패턴

| 형식 | 패턴 | 예시 (食べる taberu) |
|:---|:---|:---|
| 사전형 | -eru / -iru | 食べる (먹다) |
| ます (정중 현재) | -e + ます | 食べます |
| ません | -e + ません | 食べません |
| ました | -e + ました | 食べました |
| ませんでした | -e + ませんでした | 食べませんでした |
| て형 | -e + て | 食べて |
| た (평어 과거) | -e + た | 食べた |
| 조건형 | -e + れば | 食べれば |
| 의지형 | -e + よう | 食べよう |
| 가능형 | -e + られる | 食べられる |
| 수동형 | -e + られる | 食べられる |
| 사역형 | -e + させる | 食べさせる |

## 그룹 3: 不規則동사

그룹 3 에는 **2개 동사만** 있음 — 완전히 불규칙적으로 활용.

### する (suru) — "하다"

| 형식 | 패턴 | 예시 |
|:---|:---|:---|
| 사전형 | する | 勉強する (공부하다) |
| 정중 현재 | します | 勉強します |
| 정중 부정 | しません | 勉強しません |
| 정중 과거 | しました | 勉強しました |
| 평어 과거 | した | 勉強した |
| 조건형 | すれば | 勉強すれば |
| 부정 | しない | 勉強しない |

> **する는 생산적** — 많은 명사와 결합해 동사 생성:
> - 勉強する (benkyō suru) = 공부하다
> - 掃除する (sōji suru) = 청소하다
> - 買い物する (kaimono suru) = 쇼핑하다

### 来る (kuru) — "오다"

| 형식 | 패턴 | 예시 |
|:---|:---|:---|
| 사전형 | 来る | 来る (오다) |
| 정중 현재 | 来ます | 来ます |
| 정중 부정 | 来ません | 来ません |
| 정중 과거 | 来ました | 来ました |
| 평어 과거 | 来た | 来た |
| 조건형 | 来れば | 来れば |
| て형 | 来て | 来て |

### 그룹 1 특수 동사 (て형 불규칙)

일부 그룹 1 동사가 불규칙 て형을 가짐:

| 동사 | 의미 | 사전형 | て형 |
|:---|:---|:---|:---|
| 行く | 가다 | 行く | 行って (NOT 行いて) |
| 来る | 오다 | 来る | 来て |
| する | 하다 | する | して |

> **行く는 "거의 규칙적이지만" て형만 불규칙.**

## 그룹 식별 테스트

사전형에서 그룹 식별법:

| 마지막 글자 | 예시 | 가능한 그룹 |
|:---|:---|:---:|
| -iru (자음 후) | 起きる | **그룹 2** |
| -eru (자음 후) | 食べる | **그룹 2** |
| -ru (그 외) | 話す (su-r), 行く (i-ku, NOT -ru) | 다양 |
| -u | 飲む (no-mu), 話す (-su) | **그룹 1** |
| -ku | 書く (ka-ku) | **그룹 1** |
| -gu | 泳ぐ (oyo-gu) | **그룹 1** |
| -su | 話す (hana-su) | **그룹 1** |
| -tsu | 待つ (ma-tsu) | **그룹 1** |
| -nu | 死ぬ (shi-nu) | **그룹 1** |
| -bu | 遊ぶ (aso-bu) | **그룹 1** |
| -mu | 読む (yo-mu) | **그룹 1** |
| 정확히 する 또는 来る | する, 来る | **그룹 3** |

## 한국어 학습자가 자주 하는 실수 5가지

1. **그룹 2 혼동** — 食べる, 見る, 起きる는 -ru로 끝나지만 **그룹 2**. 그룹 1 의 -ru 동사: 走る (hashiru, 달리다), 作る (tsukuru, 만들다).
2. **行く ≠ 일반 -u 동사** — 行く은 특수. -ku 어미가 行**き**ます (일반적 -u → -i → -ます)로 변형되지만, て형만 불규칙: 行って.
3. **한국어 ~어요 ≈ 일본 ます** — 하지만 패턴이 항상 평행하지는 않음. 한국어: 먹어요 (meogeoyo), 일본어: 食べます (tabemasu). 어간 변화 다름 (食 → 食べる).
4. **ます = 정중한 동사 어미만** — 한국어 해요 (서술격 조사 함의)와 다름. 일본 ます는 동사를 정중하게 만드는 역할만.
5. **부정형 일관성** — ません는 모든 그룹에서 일관되지만, 어간 변화 다름 (그룹 1 -u → -i, 그룹 2 -e → -e 동일).

## 6단계 학습법

### Level 1 — 그룹 식별
20개 동사를 그룹 1, 2, 3으로 분류.

### Level 2 — ます형 활용
10개 동사를 ます형으로 활용.

### Level 3 — ません (부정)
5개 동사를 ません형으로 활용.

### Level 4 — ました (과거)
5개 동사를 ました형으로 활용.

### Level 5 — 그룹 1 て형
行く, 来る, する의 불규칙 て형 만들기.

### Level 6 — 그룹 3 연습
する/kuru 모든 형식 연습.
