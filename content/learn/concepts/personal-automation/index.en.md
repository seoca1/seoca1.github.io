# 개인 자동화 (Personal Automation)

## 핵심 정의

**개인 자동화(Personal Automation)** 란 **개인의 일상/업무 작업** 을 **자동화된 시스템** 으로 대체하여 시간과 에너지를 절약하는 방법론입니다. iPhone 단축어, IFTTT, Zapier, AppleScript 등 도구를 활용하여 **반복 작업의 80% 를 자동화** 하는 것이 목표입니다.

## 자동화의 5단계

### Level 1: 수동 의식 (Manual Awareness)
- 자동화 도구 인식 부족
- 모든 작업을 수동으로 실행
- 반복 작업의 비효율성 인식 못 함

### Level 2: 단축어 사용 (Using Shortcuts)
- 기성 단축어 설치/실행
- 갤러리에서 다운로드
- **효과: 시간 절감 10-20%**

### Level 3: 워크플로우 구축 (Workflow Design)
- 본인만의 단축어 제작
- 3-5단계 워크플로우
- **효과: 시간 절감 30-50%**

### Level 4: 자동화 트리거 (Trigger Setup)
- 시간/위치/앱 기반 자동 실행
- 의식 없이 자동 작동
- **효과: 시간 절감 50-70%**

### Level 5: 시스템 통합 (System Integration)
- 여러 도구/API 통합
- 생활 전반 자동화
- **효과: 시간 절감 70-90%**

## 자동화 대상 (자주 반복되는 작업)

### 1. 일상 루틴
- 모닝 브리핑 (날씨, 일정, 뉴스)
- 출근 준비 (교통, 음악, 뉴스)
- 퇴근 준비 (집 도착, 가전 제어)
- 취침 준비 (알람, 방해금지, 요약)

### 2. 정보 수집
- 주식 시세 확인
- 뉴스 헤드라인
- 이메일 정리
- SNS 알림

### 3. 데이터 관리
- 사진 자동 백업
- 명함 자동 저장
- 영수증 자동 분류
- 운동 기록

### 4. 커뮤니케이션
- 자주 보내는 메시지 자동화
- 이메일 자동 분류/회신
- 알림 통합 관리

### 5. 재무 관리
- 앱테크 출석
- 가계부 자동 입력
- 정기 결제 알림
- 투자 포트폴리오 추적

## 자동화 도구 비교

| 도구 | 플랫폼 | 강점 | 약점 |
|------|--------|------|------|
| **iPhone 단축어** | iOS | 무료, 시스템 통합 | iOS 한정 |
| **IFTTT** | iOS/Android | 다양한 서비스 | 단순한 워크플로우 |
| **Zapier** | Web | 5000+ 앱 통합 | 유료 |
| **AppleScript** | macOS | 강력한 Mac 제어 | macOS 한정 |
| **Tasker** | Android | Android 깊이 통합 | Android 한정 |
| **Make (Integromat)** | Web | 복잡한 시나리오 | 학습 곡선 |
| **Microsoft Power Automate** | Web/Windows | Office 통합 | Microsoft 생태계 |

## 자동화 설계 원칙

### 원칙 1: 자주 + 반복 = 자동화
- 매일/매주 반복되는 작업
- 5분 이상 걸리는 작업
- 실수하기 쉬운 작업

### 원칙 2: ROI 계산
```
ROI = (절약 시간 × 시간당 가치) - (설정 시간 × 시간당 가치)
```
- 양수여야 자동화 가치
- 음수면 수동이 나음

### 원칙 3: 점진적 구현
- 한 번에 5개 자동화 ❌
- 1주 1개씩 추가 ✅
- 효과 검증 후 확대

### 원칙 4: 실패 대비
- 자동화 실패 시 대안
- 수동 실행 옵션 유지
- 알림/로깅 추가

## 자동화 안티패턴

### Anti-pattern 1: 과도한 자동화
- 모든 것을 자동화하려 함
- 직접 하는 즐거움 상실
- **해결:** 핵심 3-5개만 자동화

### Anti-pattern 2: 유지보수 불가
- 복잡한 워크플로우
- 본인이 이해 못 함
- **해결:** 단순하게 유지

### Anti-pattern 3: 의존성
- 자동화 없이는 못 하는 작업
- 도구 변경 시 큰 타격
- **해결:** 수동도 가능하게

## 자동화 + 생산성 도구

### Notion / Obsidian
- 데이터베이스 자동 입력
- 일기 자동 생성
- 노트 자동 분류

### 캘린더
- 일정 자동 추가
- 알림 자동 설정
- 충돌 감지

### 이메일
- 자동 분류
- 자동 회신 (외출 중)
- 중요 메일 알림

### SNS
- 예약 게시
- 자동 응답
- 통계 추적

## 자동화 학습 로드맵

### 초급 (1-2주)
- 기성 단축어 5개 설치
- 1개 직접 만들기 (날씨 TTS)
- 시간 트리거 1개 설정

### 중급 (1-2개월)
- 3-5개 본인 단축어 제작
- 위치/앱 트리거 활용
- 조건문 사용

### 고급 (3-6개월)
- API 호출 단축어
- 다른 도구와 통합
- 복잡한 워크플로우 자동화
