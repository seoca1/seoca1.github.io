# 포트폴리오 자기 진단 (Portfolio Self-Review)

## 핵심 정의

**포트폴리오 자기 진단** 이란 자신의 **이론적 투자 원칙** (블로그 글, 학습 내용) 과 **실제 포트폴리오** (보유 자산, 배분, 비중) 를 **체계적으로 비교** 하여 **일관성** 을 점검하고 **개선점** 을 도출하는 과정입니다. 블로거의 raw/finance 50개 시트 분석을 통해 1) 이론-실제 일치도, 2) 강점, 3) 개선점, 4) Action Items 를 도출합니다.

## 비교 분석 프레임워크

### 4단계 자기 진단
1. **이론 정리:** 자신이 쓴 글, 배운 원칙 명확화
2. **실제 추출:** 스프레드시트, 브로커, 자산 목록 정리
3. **갭 분석:** 이론 vs 실제 비교표 작성
4. **액션 플랜:** 구체적 개선 항목 (1개월/3개월/6개월)

### 측정 지표
- **일치도:** 이론 항목이 실제 구현되는지 (%)
- **분산도:** 자산군/지역/섹터 다양성
- **자동화율:** 자동 매수 비중 (%)
- **세액공제 활용률:** ISA/IRP 100% 활용 여부
- **리밸런싱 빈도:** 분기/반기/연간

## 실제 사례 (블로거 포트폴리오)

### 이론 (블로그 글 8개 + 연금 글 1개)
- **Harry Browne 영구 포트폴리오** 4자산 균등
- **DCA** (정액적립식) 일관성
- **세액공제 100% 활용** (연금저축 + IRP + ISA)
- **분산 투자** (자산군/지역)
- **Modern Permanent Portfolio** (BTC/스테이블 코인)
- **Michael Saylor** BTC 국가 전략 자산

### 실제 (50개 시트)
- 36개 ISA/IRP 계좌
- 7개 미국 ETF (VTI, TLT, NOBL, XLE, GLD, MOAT, VNQ)
- 1개 한국 ETF (1476)
- 4개 개별 종목 (NAVER, Fn전기&수소차, Fn조선해운, 항셍테크)
- 2개 환전 (JPY, USD)
- 0개 디지털 자산

### 갭 분석 매트릭스

| 원칙 | 이론 | 실제 | 점수 | 개선 |
|:---|:---:|:---:|:---:|:---|
| **Harry Browne 4자산** | 25%씩 | 주식 과다, 현금 부족 | B | 비중 재조정 |
| **DCA 일관성** | 필수 | ✅ 100% 실천 | A+ | 유지 |
| **세액공제** | 100% | ✅ 100% 활용 | A+ | 유지 |

| **분산 (지역)** | 글로벌 60-70% | ✅ 글로벌 | A | 유지 |
| **BTC** | 5-10% | 0% | D | 3-5% 도입 |
| **자동화** | 권장 | 부분 | C | 자동 매수 설정 |
| **리밸런싱** | 분기별 | 미정기 | C | 분기 알림 |
| **개별종목** | 5% 이내 | 5-10% | B | 비중 축소 |

## 갭 분석 도구

### 자기 진단 체크리스트
- [ ] 영구 포트폴리오 4자산 균형인가? (25%씩)
- [ ] BTC/ETH 보유 비중? (5% 권장)
- [ ] ISA 19종 + IRP 4종 활용?
- [ ] 세액공제 1,100만원 한도 100%?
- [ ] DCA 자동화 설정?
- [ ] 분기별 리밸런싱 알림?
- [ ] 개별종목 5% 이내?
- [ ] 현금 비중 10-20%?
- [ ] 환율 변동 추적?

### 위험 신호 (Warning Signs)
- ⚠️ 포지션 50개 이상 → 과다 분산
- ⚠️ 단일 섹터 25% 이상 → 집중 리스크
- ⚠️ BTC 0% → 기회비용
- ⚠️ 현금 5% 미만 → 유동성 부족
- ⚠️ 리밸런싱 1년 이상 미실시
- ⚠️ 자동화 0% → 감정 개입 위험

## 포트폴리오 압축 가이드

## 자기 진단 보너스 팁

### 분기별 리뷰 질문
1. **내 포트폴리오가 영구 포트폴리오 4자산 균형인가?**
2. **BTC/ETH 보유 비중이 5-10%인가?**
3. **세액공제 100% 활용했는가?**
4. **DCA 자동화 설정했는가?**
5. **개별종목 5% 이내인가?**
6. **현금 15-20%인가?**
7. **리밸런싱 3개월 이내에 했는가?**
8. **새 글/원칙과 일치하는가?**

### 블로그 vs 실제 일치 매핑
- 글을 쓸 때: 실제 포트폴리오 사례 인용
- 실제 투자할 때: 쓴 글의 원칙 확인
- **자기 일관성** 유지가 핵심

## 한국 투자자 특수 고려

### 세액공제 최대화
- **연금저축:** 600만원
- **IRP:** 300만원 (연금저축과 합산 900)
- **ISA:** 200만원
- **총 1,100만원** 한도 100% 활용

### 환율 관리
- **USD:** 환전 일별 추적
- **JPY:** 일본 투자 시
- **Currency $** / **Currency ¥** 시트 활용

### 개별종목 비중
- **5% 이내** 권장
- **위험 종목:** 리츠, 반도체, 개별주 5% 이내
- **현금 15-20%** 유지 (긴급 + 기회비용)

## 심리적 측면

### 일관성 유지
- **글 = 실제:** "글에서 쓴 대로 산다"
- **자기 검증:** 분기별 "내 말이 진심인가?"
- **거짓말 방지:** 글과 다르면 글을 정정

### 감정 관리
- **DCA 일관성:** 감정 무관 매수
- **리밸런싱:** 기계적 실행
- **손절매 기준:** 사전 설정

### 배움의 순환
1. **글 쓰기** (이론 정리)
2. **실제 실행** (이론 검증)
3. **자기 진단** (갭 분석)
4. **글 업데이트** (경험 반영)
5. **반복** (지속적 개선)
