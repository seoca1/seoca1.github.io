# 평단가 평균화 수학 (Cost Averaging Math)

## 🎯 핵심 정의

**평단가 평균화(Cost Averaging)** 는 정액적립식 투자(DCA)에서 자동으로 나타나는 수학적 효과로, **고정 금액** 을 **변동 가격** 으로 매수할 때 **가중 평균 매수 단가** 가 **단순 산술 평균 가격** 보다 낮아지는 현상입니다. 이는 저가 시 자동으로 더 많은 수량을 매수하기 때문에 발생합니다.

## 📝 수학적 원리

### 단순 평균 vs 가중 평균

**단순 산술 평균 (Simple Average):**
```
단순 평균 = (P1 + P2 + P3 + ... + Pn) / n
```

**가중 평균 (Weighted Average) = DCA의 평단가:**
```
가중 평균 = 총 투자금 / 총 매수 수량
         = Σ(Fi) / Σ(Fi/Pi)
```
여기서:
- `Fi` = i번째 매수 시점의 투자 금액
- `Pi` = i번째 매수 시점의 주가

### 가중 평균 < 단순 평균의 조건
- **변동성이 있는 가격** (고가/저가 혼재)
- **고정 금액 매수** (DCA의 기본)
- **결과:** 고가 시 적은 수량, 저가 시 많은 수량

## 🔢 시뮬레이션

### 예시 1: 4개월 DCA

| 월 | 주가 (Pi) | 투자금 (Fi) | 매수 수량 (Fi/Pi) |
|:---:|:---:|:---:|:---:|
| 1월 | $100 | $1,000 | 10 |
| 2월 | $50 | $1,000 | 20 |
| 3월 | $200 | $1,000 | 5 |
| 4월 | $100 | $1,000 | 10 |
| **합계** | - | **$4,000** | **45** |

**단순 평균 주가:**
```
($100 + $50 + $200 + $100) / 4 = $112.50
```

**DCA 가중 평균 (평단가):**
```
$4,000 / 45주 = $88.89
```

**평단가 절감:**
```
$112.50 - $88.89 = $23.61 (21% 낮음!)
```

### 예시 2: 극단적 변동성

| 월 | 주가 | 투자금 | 매수 수량 |
|:---:|:---:|:---:|:---:|
| 1월 | $200 | $1,000 | 5 |
| 2월 | $50 | $1,000 | 20 |
| 3월 | $100 | $1,000 | 10 |
| 4월 | $25 | $1,000 | 40 |
| **합계** | - | **$4,000** | **75** |

**단순 평균:** ($200+$50+$100+$25)/4 = **$93.75**
**DCA 평단가:** $4,000/75 = **$53.33**
**절감:** $40.42 (**43%** 낮음!)

**핵심:** 변동성이 클수록 평단가 절감 효과 ↑

## 📐 추가 예시

### 예시 3: 강세장 (DCA의 약점)

| 월 | 주가 | 투자금 | 매수 수량 |
|:---:|:---:|:---:|:---:|
| 1월 | $100 | $1,000 | 10 |
| 2월 | $110 | $1,000 | 9.09 |
| 3월 | $120 | $1,000 | 8.33 |
| 4월 | $130 | $1,000 | 7.69 |
| **합계** | - | **$4,000** | **35.11** |

**단순 평균:** $115
**DCA 평단가:** $4,000/35.11 = **$113.93**
**절감:** $1.07 (1%만 낮음)

**→ 강세장에서는 평단가 절감 효과 거의 없음** (일시 투자와 비슷)

### 예시 4: 횡보장

| 월 | 주가 | 투자금 | 매수 수량 |
|:---:|:---:|:---:|:---:|
| 1월 | $100 | $1,000 | 10 |
| 2월 | $110 | $1,000 | 9.09 |
| 3월 | $90 | $1,000 | 11.11 |
| 4월 | $100 | $1,000 | 10 |
| **합계** | - | **$4,000** | **40.20** |

**단순 평균:** $100
**DCA 평단가:** $4,000/40.20 = **$99.50**
**절감:** $0.50 (0.5%)

## 📊 평단가 절감 효과 vs 변동성

| 변동성 (σ) | 평단가 절감 (%) | 비고 |
|:---:|:---:|:---|
| **낮음 (5%)** | 0.1-0.5% | 거의 효과 없음 |
| **중간 (15%)** | 1-3% | 보통 |
| **높음 (30%)** | 5-15% | 효과적 |
| **극단 (50%+)** | 15-40%+ | 매우 효과적 |

**Vanguard 연구 (1926-2011):**
- 평균 변동성 (S&P 500): 약 15-20%
- DCA 평균 절감 효과: 약 1-3%

## ⚖️ DCA 평단가 효과의 한계

### 효과적인 경우
- ✅ **변동성이 큰 자산** (주식, 신흥국, 원자재)
- ✅ **장기 투자** (10년+)
- ✅ **고가-저가 변동** (V자/U자 회복)

### 효과 없는 경우
- ❌ **단조 상승** (강세장)
- ❌ **단조 하락** (지속적 하락)
- ❌ **낮은 변동성** (채권, 현금)
- ❌ **단기 투자** (1년 미만)

## 🔬 수학적 증명

**가중 평균 ≤ 산술 평균 (변동성 존재 시):**

변동성 σ² > 0일 때, 가중 평균이 산술 평균보다 **반드시 작거나 같음**

이는 Jensen's Inequality에 의해:
```
f(E[x]) ≤ E[f(x)] for convex f
```

여기서 f(x) = 1/x (볼록 함수) → 결과: 평단가 ≤ 산술 평균

**증명:** Jensen's Inequality 또는 Cauchy-Schwarz 부등식

## 💡 실전 활용

### DCA 평단가 효과 극대화
1. **변동성 큰 자산에 적용** — 신흥국, 섹터 ETF
2. **고변동 시기에 집중** — 변동성 지수 (VIX) 높을 때
3. **장기 운영** — 시간 분산 효과 ↑
4. **리밸런싱 병행** — 분기별 비중 점검

### DCA 평단가 효과 약화 시
- **극단 강세장:** 일시 투자 병행 검토
- **장기 침체:** 추가 매수보다 현금 보유 검토
- **그러나:** 일관성 유지가 효과 > 시기 판단
