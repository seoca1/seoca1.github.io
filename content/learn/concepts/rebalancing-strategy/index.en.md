# 리밸런싱 전략 (Rebalancing Strategy)

## 🎯 핵심 정의

**리밸런싱(Rebalancing)** 이란 자산 가격이 변동하여 목표 비중에서 벗어난 포트폴리오를 **원래 목표 비율로 되돌리는** 작업을 의미합니다. 영구 포트폴리오의 경우 매월/분기마다 25% 균등 배분을 유지하기 위해 실행합니다. 리밸런싱은 **자동 매도-매수 효과**로 **변동성 추가 수익(Volatility Boost)** 과 **역발상 투자** 를 실현합니다.

## 📝 왜 리밸런싱이 필요한가

### 자연적 변동
- 초기: $25,000/$25,000/$25,000/$25,000
- 1년 후 (주식 강세): $35,000/$22,000/$23,000/$20,000
- 주식 비중: 25% → 35% (목표 10%p 초과)

### 리밸런싱 없이 두면 생기는 문제
- ❌ **원래 전략 의도 상실:** 주식 쏠림
- ❌ **리스크 증가:** 주가 하락 시 큰 손실
- ❌ **분산 효과 약화:** 자산 간 상관관계 ↑
- ❌ **수익률 변동성 증가**

### 리밸런싱의 효과
- ✅ **고평가 매도 / 저평가 매수** (자동)
- ✅ **분산 효과 유지**
- ✅ **감정 배제** (체계적 실행)
- ✅ **변동성 추가 수익 (Volatility Boost)**

## 🔄 리밸런싱 방법

### 방법 1: 임계점 (Threshold)
- **규칙:** 비중이 목표 대비 **5%p** 이상 벗어날 때
- **장점:** 변동 적음, 거래 비용 절감
- **단점:** 시장 급변 시 대응 늦음

**예시:**
```
목표: 25%/25%/25%/25%
주식: 31% (6%p 초과) → 리밸런싱 실행
```

### 방법 2: 정기 (Calendar)
- **규칙:** 매월/분기/반기 일정에 실행
- **장점:** 단순, 자동화 용이
- **단점:** 불필요한 거래 가능

**예시:**
```
매월 1일 / 분기 말 (3, 6, 9, 12월) / 연 2회 (6, 12월)
```

### 방법 3: 혼합 (Hybrid)
- **규칙:** 분기 정기 + 5%p 임계점
- **장점:** 균형 잡힌 실행
- **권장:** 가장 일반적

### 방법 4: 현금 흐름 활용 (Cash Flow Rebalancing)
- **규칙:** 신규 자금 유입/유출 시 활용
- **장점:** 거래 비용 제로
- **단점:** 효과 느림

**예시:**
```
월 100달러 적립 → 부족한 자산에 우선 배분
```

## 📊 영구 포트폴리오 리밸런싱 실전

### Browne의 원래 권장
> "매달 또는 분기마다 원래 25% 비중으로 맞춘다."

### 실행 단계
1. **현재 비중 확인:** 각 자산 현재 비중 계산
2. **목표 대비 차이:** 5%p 이상 변동 시 실행
3. **매도-매수:** 초과분 매도, 부족분 매수
4. **세금 고려:** 손실 매도로 세금 효율화
5. **거래 비용:** 수수료, 스프레드 최소화

### 예시 시뮬레이션

**초기 ($100,000):**
```
주식:    $25,000 (25%)
장기채권: $25,000 (25%)
단기채권: $25,000 (25%)
금:      $25,000 (25%)
```

**1년 후 (시나리오):**
```
주식:    $35,000 (35%)  +10%p
장기채권: $22,000 (22%)  -3%p
단기채권: $23,000 (23%)  -2%p
금:      $20,000 (20%)  -5%p
```

**리밸런싱:**
```
주식 매도: -$10,000 (25% 복귀)
장기채권 매수: +$3,000
단기채권 매수: +$2,000
금 매수: +$5,000
```

**결과 ($100,000):**
```
주식:    $25,000 (25%)  ✅
장기채권: $25,000 (25%)  ✅
단기채권: $25,000 (25%)  ✅
금:      $25,000 (25%)  ✅
```

## 💰 변동성 추가 수익 (Volatility Boost)

### 개념
- 리밸런싱은 **고평가 시 매도 / 저평가 시 매수**
- 시장 변동성이 클수록 효과 큼
- 추가 수익률 (연구: 연 0.3-0.5%)

### 학술 연구
- **"The Cost of Constancy"** (Dichtl, Drobetz, Wenz, 2014)
  - 60/40 포트폴리오: 리밸런싱으로 연 +0.4%
- **"The Rebalancing Premium"** (CFA Institute)
  - 5자산 균등: 연 +0.5%

### 메커니즘
- 변동성 ↑ → 매도-매수 차익 ↑
- 손실 자산 추가 매수 (저가 매수)
- 이익 자산 일부 매도 (고가 매도)
- "Buy Low, Sell High" 자동화

## 🤖 자동화 도구

### 미국 서비스
- **Betterment:** 자동 리밸런싱
- **Wealthfront:** 임계점 + 세금 효율화
- **Personal Capital:** 추적 + 알림
- **M1 Finance:** 사용자 정의 분배

### 한국 서비스
- **토스:** ETF 리밸런싱 가이드
- **나무:** 자동 리밸런싱
- **키움/KB증권:** 분기 1회 알림
- **직접:** 스프레드시트 관리

### DIY 도구
- **Portfolio Visualizer:** 백테스트
- **Google Sheets:** 자동 비중 계산
- **Python/Excel:** 리밸런싱 시뮬레이션

## ⚖️ 리밸런싱 비용 vs 이익

### 거래 비용
- **명시적:** 수수료 (0.01-0.5%)
- **암묵적:** 스프레드, 시장 충격
- **세금:** 양도소득세 (한국 22%, 미국 0-20%)

### 이익
- **변동성 추가 수익:** 연 0.3-0.5%
- **리스크 감소:** 변동성 ↓, MDD ↓
- **심리적 안정:** 원칙 준수

### 손익 분기점
- 거래 비용 < 0.5%일 때 효과적
- 분기 리밸런싱이 일반적 권장

## ⚠️ 리밸런싱 주의사항

### 하지 말아야 할 것
- ❌ **시장 예측 목적:** "내려갈 것 같으니 더 매도"
- ❌ **감정적 실행:** 공포/탐욕으로 매매
- ❌ **너무 자주:** 월 1회 이상은 과도
- ❌ **세금 무시:** 양도세 효과 고려

### 해야 할 것
- ✅ **정해진 일정:** 매월/분기 일관성
- ✅ **임계점 준수:** 5%p 룰
- ✅ **세금 효율화:** 손실 매도로 이익 상계
- ✅ **문서화:** 매매 기록 유지
