# 한국 연금 계좌 4종 세트 (Korean Retirement Account System)

## 핵심 정의

**한국 연금 계좌 시스템** 은 **세액공제 + 비과세 + 복리** 의 3중 혜택을 제공하는 4가지 계좌(연금저축펀드, IRP, ISA, 위탁) 의 조합입니다. **2025년 한국** 에서 **장기 재정 안전** 을 위해 모든 성인이 이해해야 할 **핵심 세제 혜택** 시스템이며, **55세 이후** 의 노후 생활비 (국민연금 + 개인연금) 를 결정짓습니다.

## 4대 계좌 비교

### 연금저축펀드 (연금저축)
**목적:** 세액공제 + 국내투자
- **세액공제 한도:** 연 600만원 (13.2-16.5%)
- **비과세 한도:** 55세 이후 연 1,200만원 (분리과세)
- **가입:** 증권사 / 은행 / 보험사
- **상품:** 타겟데이트펀드, 인덱스펀드, 채권, 주식혼합
- **인출:** 55세 이후 연금으로만 가능 (중도 인출 시 세금)

### IRP (개인형퇴직연금)
**목적:** 세액공제 + 퇴직금/연금 통합
- **세액공제 한도:** 연금저축과 합산 900만원
- **퇴직금 이전:** IRP로 이전 시 추가 세액공제
- **인출:** 55세 이후 연금 또는 일시금 (일시금은 세금)
- **특징:** 분리과세 3.3~5.5% (1,200만원 공제 후)

### ISA (개인종합자산관리계좌)
**목적:** 5년 만기 목돈 + 세액공제
- **3종:** 서민형 / 일반형 / 중과세형
- **세액공제:** 일반형/서민형 200만원 (9.9%)
- **비과세:** 서민형 400만원, 일반형 200만원
- **기간:** 5년 (계속 가능)
- **용도:** 내집 마련, 자녀 교육, 결혼자금

### 위탁 (증권계좌)
**목적:** 해외투자 (자유 매매)
- **세액공제:** ❌ 없음
- **양도세:** 250만원 공제 + 22%
- **용도:** 미국/글로벌 직접 투자
- **특징:** 가장 자유로운 매매

## 4종 세트 총혜택

### 세액공제 한도 합계
- 연금저축 600 + IRP 300 (합산 900) + ISA 200 = **1,100만원**
- **공제율 (13.2-16.5%):** 최대 145-181만원 환급
- **세액공제 한도 초과 시:** ISA 또는 위탁

### 비과세 한도
- ISA: 서민 400 / 일반 200
- 연금저축/IRP: 1,200 (분리과세)
- **총 최대:** 1,600만원 (서민형 + 연금)

## 4종 세트 구축 전략

### 단계별 구축 (블로거 사례)

| 나이 | 1단계 | 2단계 | 3단계 | 4단계 |
|:---|:---|:---|:---|:---|
| **20대** | 연금저축 시작 | - | - | ISA |
| **30대** | + IRP | + 위탁 | - | - |
| **40대** | + ISA | 4종 완성 | - | - |
| **50대** | 최대 납입 | 비중 조정 | - | - |

### 월 납입 가이드 (예시)

| 계좌 | 월 납입 | 연간 | 세액공제 (15%) |
|:---|:---:|:---:|:---:|
| 연금저축 | 50만원 | 600만원 | 90만원 |
| IRP | 25만원 | 300만원 | 45만원 |
| ISA (서민) | 33만원 | 400만원 | 39.6만원 |
| **합계** | **108만원** | **1,300만원** | **175만원** |

## 한국 연금 시스템 구조

### 3층 구조
```
1층: 국민연금 (공적연금, 4.5% / 9%)
2층: 퇴직연금 (DB/DC, 회사 부담)
3층: 개인연금 (연금저축, IRP) + ISA + 위탁
```

### 55세 이후 시나리오

| 구분 | 금액 (월) | 출처 |
|:---|:---:|:---|
| 국민연금 | ~60만원 | 4.5%/9% × 40년 |
| 회사 퇴직금 (DC) | ~50만원 | 회사 부담 |
| 연금저축+IRP | 80-100만원 | 1,000만원+ → 연금 |
| ISA (5년 만기) | 100만원 | 1,000만원 → 인출 |
| **총** | **290-310만원** | 1-3층 통합 |

## 2025년 최신 변경사항

### 세액공제
- **연금저축:** 600만원 한도 유지
- **IRP:** 300만원 추가 (연금저축과 합산 900)
- **세액공제율:** 13.2-16.5% (총급여 5,500만원 기준)

### 비과세 한도
- **연금저축/IRP 분리과세:** 1,200만원 공제
- **초과분:** 16.5% 분리과세 (낮음)

### 한도 초과 시
- ISA 추가 납입 (세액공제 가능)
- 위탁 (해외투자, 양도세)

## 세대별 권장 전략

### 20대 (사회초년생)
- **월 10-30만원:** 연금저축
- **소득 적을 시:** ISA 서민형
- **장점:** 복리 시간 극대화

### 30대 (결혼/출산기)
- **월 30-50만원:** 연금저축 + IRP
- **목돈:** ISA
- **해외:** 위탁

### 40대 (자산 증식기)
- **월 50-100만원:** 4종 균형
- **세액공제 최대 활용**
- **부동산 일부 매각 → 연금 전환**

### 50대 (은퇴 준비기)
- **최대 납입:** 1,100만원 한도
- **리스크 축소:** 채권/예금 비중 ↑
- **ISA 활용:** 5년 만기 인출

## 가상자산과의 관계

### 현재
- 가상자산 = 별도 계좌 (4종 외)
- 2027년까지 양도세 유예
- 250만원 공제 + 22%

### 미래 (2027+)
- 가상자산 과세 본격화
- 별도 가상자산 ISA 가능성
- 4종 + 가상자산 = 5종 세트

## 실전 가이드

### 1단계: 가입 순서
1. **연금저축:** 증권사 (예: KB, 미래에셋)
2. **IRP:** 증권사 (연금저축과 동일)
3. **ISA:** 은행/증권사
4. **위탁:** 증권사 (해외)

### 2단계: 매년 말 체크
- [ ] 연금저축 600만원 납입
- [ ] IRP 추가 (가능 시)
- [ ] ISA 납입 (세액공제 한도)
- [ ] 위탁 비중 점검

### 3단계: 리밸런싱
- 분기 1회: 4종 비중 점검
- 1년 1회: 자산군 재배분
- 라이프스테이지: 나이별 비중 조정

## 한국 투자자 자주하는 실수

### 실수 1: 한 종류만 사용
- ❌ 연금저축만 1,000만원 (한도 600)
- ✅ 4종 균형 (1,100만원 + 위탁)

### 실수 2: 중도 인출
- ❌ 결혼자금으로 연금저축 인출 (세금 폭탄)
- ✅ ISA 활용 (비과세 인출)

### 실수 3: 국내만 투자
- ❌ 4종 모두 국내 펀드
- ✅ 위탁 + 해외 ETF (S&P 500, NASDAQ)

### 실수 4: 은퇴 후 한꺼번에 인출
- ❌ 55세에 일시금 (세금)
- ✅ 분할 인출 / 연금화
